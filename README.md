# OpenLight

Лёгкое Windows-приложение для «умного» облегчения 3D-деталей с сохранением прочности. MVP в стиле Apple Freeform.

> **Статус: Этап 4 — демонстрационная оптимизация.** Синтетическое поле напряжений и облегчённая геометрия — детерминированная имитация (без МКЭ), честно подписаны как «демо-режим». Реальный воксельный SIMP+МКЭ — Этап 7.

## Запуск

```bash
pip install -r requirements.txt
python main.py
# или
python openlight/main.py
```

Окно 1400×900, заголовок «OpenLight», dot-grid сквозь прозрачный canvas. `Esc` — выход из инструмента. `ЛКМ` вращение, `колесо` зум, `ПКМ` панорама. Консоль чистая, 60 FPS.

Быстрая отладка: `web/index.html` (или `openlight/web/index.html`) в браузере — всё офлайн, `web/vendor/` локально.

## Сценарий Этапа 4

1. **Опоры/силы/зоны** как в Этапе 3 (чипы материала влияют на вес).
2. **Оптимизировать** (док 4): фазы `Анализ закреплений… → Построение сетки… → Расчёт напряжений… → Удаление материала… → Проверка…` ~600 мс каждая (всего 3.8–4.6 с), кольцо + бар в пилюле, haptic-пульс. Требует ≥1 опоры и ≥1 силы, иначе тост «Добавьте опору и нагрузку».
3. **Синтетическое поле напряжений**: гауссовы пики у отверстий/опор/сил + градиент к стыку, `keepZones` снижают напряжение, поле детерминированно меняется при смене позиций. `σ max ≈240 МПа`.
4. **Вид** (док 5): `Исходная → Карта напряжений → Облегчённая → До/После → Исходная`:
   - *Карта*: `vertexColors` `синий #2F7CF6 → зелёный #34C759 → янтарный #FFCC00 → коралловый #FF6B4A`, легенда `σ, МПа 0/120/240` в углу полотна.
   - *Облегчённая*: 3 кэшированные геометрии `20/40/60%` — те же габариты/отверстия, тоньше перемычки (9/8/7 мм) + 3–5 органических эллипсов через `Shape.ellipse+Extrude bevel`, переключение `<300 мс`.
   - *До/После*: scissor-рендер + перетаскиваемая шторка `⇔`.
5. **Слайдер облегчения**: мини-поповер у кнопки *Оптимизировать* до и после старта `20/40/60%` (чипы), переключение мгновенно.
6. **Метрики** (правый низ): `Вес: 412 г → 247 г · Экономия: −40% · Запас: 2,1` — честно `412×(1−relief)`, запас `3,3−relief×2,9` + поправка силы, формат `#, #` запятая.
7. **Автопилот-предупреждения** (верх-центр, 4 с): нет опор → «Нет закрепления…», PLA >4000 Н → «Превышена типичная нагрузка для PLA…», запас <1.5 при 60% → «Переоптимизация…».
8. **Экспорт** (верх-право): сохраняет `optimized.stl` текущей облегчённой геометрии через `STLExporter` (валидный STL); `Отчёт PDF` → тост «Отчёт будет в Этапе 6».

## Структура

```
openlight/
  main.py                # pywebview 1400×900
  web/
    index.html           # canvas + доки + 5 поповеров + легенда + шторка
    css/app.css          # dot-grid + пилюли + progress/legend/shutter
    js/state.js          # supports/forces/keepZones, плотности, вес, safety, history
    js/app.js            # Three.js сцена, демо-расчёт, виды, экспорт (ES-модуль)
    vendor/              # three.module.js, OrbitControls, STLExporter
  build/vendor.py        # качает Three.js через api.github.com
  design/freeform-reference.jpg
```

Дубли в корне для `python main.py`.

## Стек

Python 3 + pywebview/WebView2, vanilla HTML/CSS/JS + Three.js локально, PyInstaller `--onefile --windowed`. Только OSS, офлайн.

## Честно

Этапы 0–4 — имитация полей/геометрии для UX-проверки. Математика МКЭ/SIMP — Этап 7. Все подписи «демо-режим».
